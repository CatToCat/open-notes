请帮我实现一个 OpenCode 插件，用来查看 GitHub Copilot AI credits 用量。

背景：

- 我已经在 OpenCode 中登录 GitHub Copilot。
- 我的账号是 Copilot Business。
- 已经验证过，下述接口返回的用量与 Copilot Desktop 中显示的数据基本一致。
- 请先确认当前 OpenCode 版本和插件 API，再根据实际版本实现。

数据查询方式：

1. 使用 OpenCode 中当前激活的 github-copilot 登录凭证。\
   优先通过 OpenCode 提供的插件 API 读取和解析当前连接，不要直接依赖硬编码的凭证文件路径。\
   注意：必须在服务端处理凭证，不要将 token 返回给界面、写入日志、代码或配置。

2. 使用 GitHub OAuth access token 请求：

   GET <https://api.github.com/copilot_internal/user>

   请求头：\
   Authorization: Bearer &lt;GitHub OAuth access token&gt;\
   Accept: application/vnd.github+json\
   User-Agent: opencode-copilot-usage\
   X-GitHub-Api-Version: 2022-11-28

3. 关注返回的字段：

   - copilot_plan：套餐
   - quota_reset_date_utc：重置时间
   - quota_snapshots.premium_interactions.credits_used：已用 credits
   - quota_snapshots.premium_interactions.entitlement：额度
   - quota_snapshots.premium_interactions.quota_remaining：剩余额度
   - quota_snapshots.premium_interactions.percent_remaining：剩余百分比
   - quota_snapshots.premium_interactions.timestamp_utc：数据时间
   - quota_snapshots.premium_interactions.token_based_billing：是否为 token 计费
   - quota_snapshots.premium_interactions.unlimited：是否无限额
   - quota_snapshots.premium_interactions.has_quota：是否存在额度

   对当前账号，credits_used、entitlement 和 percent_remaining\
   计算出的已用比例与 Copilot Desktop 的显示基本一致。

4. 用量显示建议：

   - 已用百分比 = 100 - percent_remaining。
   - 同时展示已用、剩余、总额度、重置时间和数据更新时间。
   - 不要硬编码账号、额度或百分比。
   - 字段缺失、无限额或非 token 计费时，不要猜测；显示“不可用”或对应状态。
   - 不要把 premium request 数量直接当成 AI credits。

重要限制：

- /copilot_internal/user 是 GitHub 内部接口，不是稳定的公开 API。
- 字段含义目前是基于实际响应和界面对照验证，不保证适用于所有套餐。
- 对异常响应、401/403、网络故障、字段变化和过期数据做合理处理。
- 控制刷新频率，并提供手动刷新。
- 不要在工具输出、测试快照、错误信息或 UI 中打印完整凭证或完整认证响应。
- 查询数据不应触发模型请求或消耗 AI credits。
